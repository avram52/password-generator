# 🔐 Password Generator with Visual Slider

A secure, user-friendly password generator inspired by **Proton Pass** with a visual slider bar for length control.

![App Screenshot](screenshot.png) <!-- Add your actual screenshot here -->

## ✨ Features

- 📊 **Visual Slider Bar** - Drag to set password length (8-64 characters)
- 🔒 **Secure Generation** - Random alphanumeric combinations with optional symbols
- ✅ **Flexible Options** - Choose which character types to include
- 💻 **Beginner-Friendly** - Clean Python code perfect for your portfolio
- 🚀 **No Extra Install** - Uses built-in `tkinter` module
